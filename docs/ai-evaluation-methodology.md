# AI Evaluation Methodology — Technical Interview Reasoning Coach

## Core Differentiators & Principles

1. **Evidence Verification & Anti-Hallucination Guard**
   - Every strength and weakness generated by the LLM is checked against the candidate's actual text.
   - Exact case-insensitive substring matching is evaluated first.
   - If exact match fails, a sliding-window Levenshtein similarity algorithm compares candidate text windows against the cited evidence.
   - Any evidence scoring below 85% similarity is discarded silently to guarantee zero hallucinated feedback.

2. **Deterministic Scoring**
   - The backend recomputes the `overallScore` as the mean of applicable category scores.
   - If the AI-returned `overallScore` deviates from the computed mean by > 5 points, a prompt-quality monitoring warning is logged.

3. **Prompt Injection Defense**
   - Candidate explanations and code are enclosed within `<candidate_response>` XML tags.
   - System prompts explicitly direct the model to treat content inside XML tags strictly as untrusted data and ignore embedded instructions.

4. **Async-Safe Execution**
   - LLM API calls execute outside database transactions to prevent connection pool exhaustion during the 30-second timeout window.
